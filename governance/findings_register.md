# AA Findings Register

This register records only evidence-backed conclusions. It must not become a place for opinions, guesses, or premature certainty.

## Register Fields

Each entry must include:

- Date
- Status: Observation / Hypothesis / Emerging Finding / Finding / Retired
- Claim
- Sample size
- Time range
- Pairs involved
- Sessions involved
- Evidence
- Contradictory evidence checked
- Confidence
- Owner
- Next review trigger
