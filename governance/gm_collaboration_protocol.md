# GM Collaboration Protocol

**Status:** Active Protocol
**Scope:** AG, Codex, GM

## Communication Standard
AG will treat repository artifacts as the primary communication channel. Chat interfaces are for notification only.

When AG completes work, the chat notification must strictly contain:
1. Repository path
2. Commit hash
3. One-line purpose
4. Status: Awaiting GM Review

## Behavioral Constraints
* **No Chat Summaries:** AG will not summarize conclusions in chat unless explicitly asked.
* **No Validation Claims:** AG will not state that a report "validates" AA.
* **No Findings:** AG will not convert research into findings.

## Report Formatting
All future research reports produced by AG must separate content into the following structure:
* Evidence
* Interpretation
* Hypothesis candidates
* Contradiction tests
* Open questions

Every report must conclude with the exact phrase:
`GM Review Required`

## Governance Workflow
The GM will read artifacts directly from the repository and hold sole authority over deciding what is promoted to a hypothesis, contradiction test, or finding.

## Evidence Channels

Two formal channels of evidence are recognized:

1. **Live Trade Evidence:** Reports generated from AA's active trading records submitted by AG in standard report format.
2. **Evidence Recovery Ledgers:** Structured CSVs generated by AG's offline Evidence Recovery pipeline. These are submitted via repository commit only. AG notifies GM in chat with path, commit hash, and one-line purpose.

Both channels are subject to the same governance workflow:

  Data → Observation → GM Review → [Hypothesis | Archived]
