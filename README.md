# AA Research

Official repository-backed source of truth for AA research.

## Mission

Determine where FX opportunities disappear across the trading pipeline and whether AA can generate sufficient high-quality FX flow to support a profitable trading business.

The objective is understanding.

The objective is not optimization.

## Governance

- Observation is not hypothesis.
- Hypothesis is not finding.
- Finding requires surviving contradiction.
- Evidence alone does not authorize change.
- Recommendations require explicit GM request regardless of evidence strength.
- Repository contents override memory, assumptions, prior conversations, and agent recollection.

## Structure

- `governance/`: mission, policy, team roles, and governance memos
- `docs/`: shared human-readable research memos
- `reports/`: daily, weekly, monthly, and research reports
- `ledgers/`: opportunity, blocked-opportunity, and trade-history ledgers
- `hypotheses/`: active and retired hypotheses
- `findings/`: promoted findings after evidence review
- `memory/`: durable project memory shared across agents

## Safety

This repository must not contain secrets, API keys, Saxo credentials, broker account identifiers, `.env` files, raw database files, or personal sensitive data.
